# Méthodes d'Apprentissage Pilotées par l'IA (MAP) 🚀

Bienvenue sur ce dépôt. À l'ère des modèles de langage (LLM) et des assistants de code, la manière d'apprendre la programmation a radicalement changé. Ce dépôt centralise mes chartes et frameworks personnels d'apprentissage pour **dompter l'IA sans détruire sa propre logique ni saboter ses compétences d'ingénieur.**

L'objectif ici est simple : passer du statut de simple consommateur de code généré à celui d'architecte et de réviseur critique. 

---

## 📋 Sommaire des Chartes

Ce dépôt contient trois guides méthodologiques stricts, applicables au quotidien :

*   **[MAP - Version Backend](MAP_Backend.md) :** Ma feuille de route chirurgicale pour concevoir, structurer et sécuriser du code côté serveur en JavaScript Vanilla, en utilisant l'IA uniquement comme tuteur socratique.
*   **[MAP - Version Frontend](MAP_Frontend.md) :** Une méthode asymétrique pour maîtriser le HTML sémantique et les structures de mise en page, tout en déléguant efficacement le design cosmétique à l'IA pour gagner du temps.
*   **[Guide de Musculation Logique (GML)](Musculation_Logique.md) :** Mon programme d'entraînement quotidien (30 à 45 min) sur les algorithmes et les structures de données pour réussir les tests techniques et les entretiens de Live Coding.

---

## 💡 Philosophie Générale

1. **Maîtriser avant de déléguer :** Si tu ne peux pas expliquer le code généré par l'IA à un enfant de 10 ans, ce code n'a rien à faire dans ton projet.
2. **La règle du 10 pour 1 :** Passer 10 fois plus de temps à lire, décortiquer et comprendre une ligne de code optimisée par l'IA que le temps qu'il lui a fallu pour la générer.
3. **L'IA est un débloqueur conceptuel, pas un nègre littéraire :** On l'utilise pour comprendre ses erreurs et explorer des cas limites (*edge cases*), jamais pour esquiver l'effort de réflexion logique.

---

## 🛠️ Utilisation

Ces guides sont libres d'accès. Si vous êtes étudiant, développeur autodidacte, ou que vous vous perdez dans la boucle infinie du copier-coller des LLM, n'hésitez pas à vous approprier ces chartes pour vos propres projets. 

*Le code est un outil de traduction ; la logique reste un art humain.*
